# How to Keep a Website From Looking Vibecoded: Do's and Don'ts

## Don't (Design)

- Harsh gradients, especially purple gradients
- Purple and black color combo
- Neon colors
- Basic pastel colors
- Rainbow coloring
- Clashing colors
- Pure white background
- Lucide icons everywhere
- Sparkle icons
- Emojis as icons or in text
- Drop shadows
- Liquid glass effect
- Bento grids
- 3 feature cards in a row
- Colored left stripe on cards
- Terminal window mockup
- Radial orbs
- Dot grid backgrounds
- Animated arrows
- Same soft corner radius on everything
- Overdone hover animations
- Too many scroll effects
- Cursor effects
- Inter / Geist / Space Grotesk as the default font

## Don't (Content)

- Em dashes
- "It's not X, it's Y" style copy
- Checkmark bullets everywhere
- Fake testimonials
- Default 3 pricing tiers
- Lorem ipsum
- Placeholder text
- Unused nav items

## Don't (Technical)

- Horizontal scroll
- Console errors
- Production source maps
- Huge JS bundles
- Broken links
- Broken buttons
- Mobile overflow

## Do (Design and UX)

- Clear hierarchy
- Readable type sizes
- Consistent spacing
- Even margins
- Layouts with breathing room
- Less clutter
- Polished above-the-fold section
- Clickable, consistent buttons
- Hover states
- Loading states and skeleton loaders
- Form success and error messages
- Real product demos
- Clickable logo, phone number, and email
- Full mobile optimisation, with a mobile menu

## Do (Pages and Trust)

- Terms of Service
- Privacy policy
- Working footer links
- Custom 404 page
- Current copyright year

## Do (SEO and Technical)

- Custom domain
- A URL for every page
- Unique page titles
- Meta descriptions
- One clear H1 heading
- Canonical tags
- sitemap.xml
- robots.txt
- Server-side rendering
- Internal links
- Breadcrumbs
- Favicon
- Business schema
- Alt text on images
- Share images (Open Graph)
- Compressed images

## Helpful Tools

- shadcn/ui
- motion.dev
- React Bits

## Final Check Before Deploy

- [ ] No purple gradients, emojis, em dashes, or lorem ipsum
- [ ] No horizontal scroll on mobile
- [ ] No console errors
- [ ] All links and buttons work
- [ ] Favicon, title, and meta description set
- [ ] 404 page, Terms of Service, and privacy policy added
- [ ] Images compressed
- [ ] Hover, loading, success, and error states done
